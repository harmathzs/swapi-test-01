# swapi-test-01

Vite + React site showing Star Wars films from https://swapi.dev.

Requires Node.js 18.20.8 or a newer version supported by the configured toolchain. The build tooling is pinned for Node 18 compatibility. Node 18 is end-of-life and no longer receives security updates; use a supported Node.js release where possible.

`npm install`, `npm run dev`, `npm run build`
